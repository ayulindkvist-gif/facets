# ГРАНИ — статическая сборка для GitHub Pages

Это **готовая собранная версия** платформы музейных клубов «Грани».
Папка содержит только статические файлы (HTML / CSS / JS / картинки) и подходит для бесплатного хостинга на GitHub Pages.

## Как опубликовать на GitHub Pages

1. **Создайте репозиторий** на GitHub (имя — любое, например `grani-museum`).
2. **Загрузите содержимое этой папки в корень репозитория** (не саму папку, а её содержимое):
   - через веб-интерфейс — кнопка **Add file → Upload files**, перетащите всё содержимое и нажмите **Commit changes**;
   - либо через командную строку:
     ```
     git init
     git add .
     git commit -m "Initial deploy"
     git branch -M main
     git remote add origin https://github.com/<ваш-логин>/<имя-репо>.git
     git push -u origin main
     ```
3. **Включите GitHub Pages**:
   `Settings` → раздел `Pages` → **Source: Deploy from a branch** → **Branch: `main`**, **Folder: `/ (root)`** → **Save**.
4. Через 1–2 минуты сайт появится по адресу
   `https://<ваш-логин>.github.io/<имя-репо>/`

## Маршруты

Сайт использует **HashRouter**, поэтому все внутренние ссылки идут через `#`:

- главная — `https://<ваш-логин>.github.io/<имя-репо>/`
- клубы — `…/#/clubs`
- музеи — `…/#/museums`
- регистрация — `…/#/register`
- вход — `…/#/login`

Это нормально и нужно для того, чтобы переходы работали на GitHub Pages без 404-ошибок при перезагрузке страницы.

## Что внутри папки

```
.nojekyll         ← отключает обработку Jekyll (важно для корректной работы)
README.md         ← этот файл
index.html        ← точка входа
favicon.svg
icons.svg
assets/           ← собранные JS- и CSS-бандлы
artwork/          ← 20 изображений произведений (o1.jpg … o20.jpg)
images/
  ├─ museums/     ← 8 фото музеев
  └─ clubs/       ← 9 обложек клубов
```

Файлы `.htaccess` и `_redirects` остались с настроек других хостингов — на GitHub Pages они просто игнорируются и не мешают.

## Проверить локально перед загрузкой

В этой же папке выполните:

```
npx serve -s . -l 5000
```

и откройте `http://localhost:5000/` — это точная имитация того, как сайт будет работать на GitHub Pages.

## Данные

Приложение полностью клиентское: все заметки, логин и прогресс хранятся в `localStorage` браузера. Бэкенд не нужен.
